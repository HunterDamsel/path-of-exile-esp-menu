## 🧩 About

**Path of Exile overlay Menu** is a curated list of Path of Exile open-source tools:

- **Overlays** — on-screen helpers, layout notes, area labels, menu panel
- **Quality-of-Life Helpers** — loot notes, map tracker, config manager
- **Research Notes** — atlas layouts and build notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Overlay Helpers
- Area Overlay — label zones and waypoints on screen
- Menu Panel — toggle a compact on-screen menu
- Loot Labels — highlight item drops for study
- Map Notes — annotate atlas routes and layouts

### 🎨 Catalog & Config
- Item Catalog — browse base types, mods, and tiers
- Build Notes — organize passive trees and gem setups
- Stash Notes — plan tab layouts and sorting rules

### 🏋️ Study Layout
- Atlas Notes — segment map study on any layout
- Trade Notes — record price checks for review
- Filter Notes — organize loot filter rules in the editor
